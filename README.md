# CPRD-Katie-DePICtion-paper

This repository contains the R code for the paper "Implementing a clinical prediction model in UK primary care data to identify individuals with misclassified diabetes: a population based retrospective cohort study", which is part of the NIHR SPCR funded DePICtion (Diabetes in Primary Care – Improving Classification) study. See https://github.com/Exeter-Diabetes/CPRD-Codelists/ for information on codelists used.
